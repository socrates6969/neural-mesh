# lessons K1 (knowledge-store growth / compaction / freshness on real-text worlds A,B; all numbers SYNTHETIC-until-validated: real paragraphs/queries/vectors, synthetic edits/arrivals/popularity/outcomes)
- Store growth alone costs retrieval: hit@1 .304 -> .209 (A) / .278 -> .188 (B) from 25 % to 100 % of the stream (4x rows of near-sibling fragments); a ~16 % superseded-row share keeps ~8-10 % of top-1 results stale.
- Freshness lever = structural key + revision stamp supersession (-35 % bytes, stale top-1 -> 0, hit@1 +.014..+.017, MRR +.029..+.031, Holm gains in both stages in A and B); gain scales with the stale share (norev: 0, hirev: +.020/+.022) and drops by ~1/3 without revision stamps (late arrivals). Soft penalty (>=2 z) gives the same quality but no bytes.
- Cosine rules do not detect revisions: keep-first merge loses quality monotonically below theta .98 and never fixes staleness; keep-newest (theta .75-.85) is a revision-dependent accident (+.003..+.005 hit@1 with revisions, -.009/-.010 on a no-revision stream, MRR -.003..-.009). g16/h6's cosine negative reproduced in kind.
- Free byte savings: block-fp16 -42 % bit-identical; int8 cold / age tiers -47..-68 % total bytes at |d| <= .0003 hit@1/MRR, EQ(+-.01) both stages both worlds, loop 9-10/10 EQ cells; sparse postings (8 %) and metadata (1.4 %) cap the total.
- Byte-cap eviction loses on uniform queries (FIFO < LRU < usage-value, opposite of h4's routing memory because documents do not expire); usage-value only wins hit@1 under popularity-weighted queries with informative feedback (+.02..+.03) and costs MRR; random-credit control loses -.05..-.09.
- Anchor-summary rows keyed by structural section still lose (-.004..-.0075 hit@1, -19.5 % bytes only, stale@1 rises); h6's negative stands.
- End to end the loop barely moves (4-12 % of the oracle gain captured by retrieval in T12; no Holm-significant negative cell for non-eviction arms, no replicated positive cell): loop equivalence is low-powered (paired SD ~10x retrieval metrics), "not EQ" = inconclusive.
- Traps: a cosine/threshold rule's quality depends on the staleness of the stream, so always run no-revision and high-revision controls; picks tuned on A transferred to B; EQ at +-.01 can hide small significant losses (cosfirst0.98, summary) -> read the CIs; hit@1 absolute level is only ~.2 on real near-sibling paragraph fragments.
