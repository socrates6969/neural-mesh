 (3) The big lever on real text is the hybrid, not the spell-corrector: z-score fusion dense+BM25 (alpha .7, tuned on A tune seeds) adds +0.040 [A held] / +0.048 [A confirm] / +0.028 [B confirm] MRR over spell-dense (Holm *, cluster-bootstrap CI [+.033,+.059]/[+.032,+.058]/[+.014,+.041]); g1 had +.012. Hybrid-with-spell beats hybrid-without by +0.015..+0.017 MRR (all of it on typo queries, +.06; ~0 on clean).
 (4) CompactRouter u16/q16 vs f64 recommended router on a real-text-shaped replay: CERTIFIED equivalent at +-0.005 (TOST, Holm) in all 8 worlds, pooled seeds 31-90, and at +-0.003 on 160 fresh seeds; max |mean diff| 0.0003; compact-f64 bit-identical (0e0). Caveat below: the routers barely beat the keyword prior here (+.010..+.013), so this is a weaker test than a world with large learning headroom. compact is also 2.6x-4.6x faster per decision on this long-tailed real vocabulary (shared box).
 (5) serve fix: replies BYTE-IDENTICAL to HEAD 52f936c in all 14 scenarios (+14 base-vs-base controls, harness self-test sees a 1-byte change) with real-text request payloads; real-payload decisions/s: lockstep N=1 478 -> 3330 (6.9x), N=4 1323 -> 3993 (3.0x), pipelined N=1 640 -> 6442 (10.2x), stdio 1.10x (inside g6's noise floor).

NEGATIVES / CAVEATS (blunt)
 1. Relevance judgments are structural (section membership / source paragraph), not human-rated: duplicate-ish paragraphs across crates not caught by exact/Jaccard>=.6 dedup would count as misses (understates all systems equally); absolute hit@1 ~.2.
 2. H queries share vocabulary with their section body (titles); S queries lose one sentence but keep the topical words; both favour lexical methods more than real "natural-language question -> doc" use would. Spell-corrector vocabulary = docs only (OOV query words absent from docs get altered: the clean-query harm).
 3. t-CIs over seeds resample subsets of ONE finite query pool (1566 / 1557 / 1029 distinct queries) and typo draws; they are too narrow for contrasts that differ by query (dense vs BM25); read the cluster-bootstrap CIs. A->B is the independent replication (A and B share no text; A confirm is not independent of A held in the pool sense).
 4. Typos are synthetic and applied to 4+-letter words only; real typo mixes (real-word errors, phonetic errors, word breaks) are only represented by n=10.
 5. Replay worlds: features are rare content words of real sentences, so the learner sees a real long-tailed vocabulary, but the competence map is a stylised cluster -> agent table; routers gain only +.002..+.013 over the keyword prior, which limits what the equivalence test can show (see NUMBERS 2). 8 worlds are 4 resamplings of 2 text sources x vocabulary regimes, not 8 independent worlds.
 6. Speed ratios are from a box with 60-87% background CPU; use the paired ratios, not absolute rates. compact vs f64 ns/decision includes the same env/outcome overhead on both sides.
 7. World B drifts if rebuilt (it reads live results/*.md and src comments); fixtures + md5 are the artifact. Baseline exe build overwrites release/neural-mesh.exe in the shared target dir (same as g6).
 8. One embedder (MiniLM), one distance, brute force scan; hybrid alpha tuned only on the A tune pool (alpha .7 for both arms; grid in results/h10_picks.json).
